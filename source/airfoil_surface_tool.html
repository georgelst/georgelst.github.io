Imported points
The imported point set is split at the leading edge, reconstructed branch by branch, and then reassembled as a smooth airfoil contour. The displayed camber corresponds to the current linear approximation.

Camber distribution

The current linear-approximation camber line is reported separately as a chordwise distribution on the common analysis grid.

This curve is obtained directly from the reconstructed upper and lower branches as the current linear approximation, y_c(x) = [y_u(x)+y_l(x)]/2.

Thickness distribution

The thickness is evaluated as the vertical distance between reconstructed upper and lower surfaces on the common analysis grid.

This is a high-quality chordwise extraction step. A later version can add nonlinear normal-based pairing.

Distribuição de linha média

A linha média da aproximação linear atual é apresentada separadamente como uma distribuição ao longo da corda na malha comum de análise.

Esta curva é obtida diretamente dos ramos superior e inferior reconstruídos como a aproximação linear atual, y_c(x) = [y_u(x)+y_l(x)]/2.

Distribuição de espessura

A espessura é avaliada como a distância vertical entre as superfícies superior e inferior reconstruídas na malha comum de análise.

Este é um passo de extração cordal de alta qualidade. Uma próxima versão pode adicionar o pareamento não linear por normais.
